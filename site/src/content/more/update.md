MaiMotionDemo 每次開啟都會檢查有沒有新版。在 Windows 上可以直接在程式裡下載、重新啟動就換成新版；你的紀錄與設定都會保留。

## 有新版時會怎樣

每次開啟程式都會自動向 GitHub 查一次。有新版時，右下角會出現「有新版本 vX.Y.Z」的通知。沒有新版或查詢失敗時不會打擾你。

也可以隨時到「設定 → 版本與更新」，在「軟體更新」按「檢查更新」手動查。離線或 GitHub 忙碌時會檢查失敗，不影響使用，稍後再試即可。

## 在程式裡更新（Windows）

1. 在通知上按「下載更新」（或在「設定 → 版本與更新」按「下載並更新」）。
2. 通知會顯示已下載的大小與進度條。下載完成後，程式會核對檔案的 SHA-256。
3. 出現「已下載」的通知後，按「重新啟動」（設定裡是「重新啟動並更新」）。
4. 程式會開啟新版並關閉舊版。

## 新版下載到哪裡

新版會下載到**目前程式所在的資料夾**。這個資料夾不能寫入時，改放到「下載」資料夾。

## 舊版的執行檔怎麼處理

新版開啟後，會自動刪除舊版的執行檔，並在右下角通知「已更新到 vX.Y.Z」。

- 只刪**同一個資料夾**裡的舊版 MaiMotionDemo。
- 新版下載到「下載」資料夾時，舊版會保留，可以自己刪除。
- 舊版沒刪成功時，通知會寫出原因和舊版的位置，之後自己刪除即可。

## 更新後紀錄還在嗎

在。譜面紀錄、設定與下載的影片都存在本機資料夾，更新後全部保留。

## 下載失敗怎麼辦

出現「更新下載失敗」時，按通知上的「到 GitHub 下載」，手動下載新版取代舊檔。最新版在[下載頁](/download)；要找舊的版本，見 GitHub 的[所有版本](https://github.com/silver0416/MaiMotionDemo/releases)。

## 看這次更新了什麼

新版開啟後，「已更新到 vX.Y.Z」的通知上有「查看更新內容」：

- 依這次跨了幾版，列出舊版之後到這一版的**每一版**更新說明，新版在前。
- 內容和 GitHub 發布頁相同，只是不列下載說明。
- 需要連網。

通知關掉之後，也可以在「設定 → 版本與更新」的「版本資訊」按「查看更新內容」再看一次。

## macOS 與 Linux 怎麼更新

程式內的自動下載目前**只支援 Windows**。macOS 與 Linux 版有新版時一樣會提示，按「前往下載」到 GitHub 下載新版，自己替換。
