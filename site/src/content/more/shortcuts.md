所有按鍵整理在這裡。每張表都註明在哪個畫面有效；游標在文字輸入欄裡時，按鍵不會被攔截，可以正常打字。

## 播放與時間軸

在主視窗、沒有對話框開著時有效。

| 按鍵 | 做什麼 |
| --- | --- |
| <kbd>Space</kbd> | 播放／暫停 |
| <kbd>←</kbd> <kbd>→</kbd> | 後退／前進 0.1 秒 |
| <kbd>Shift</kbd>+<kbd>←</kbd> <kbd>→</kbd> | 後退／前進 1 秒 |
| <kbd>Home</kbd> | 回到開頭 |
| <kbd>L</kbd> | 開關循環片段 |
| <kbd>I</kbd> | 目前時間設為片段起點（並打開循環） |
| <kbd>O</kbd> | 目前時間設為片段終點（並打開循環） |
| <kbd>M</kbd> | 在目前時間加標籤 |
| <kbd>[</kbd> <kbd>]</kbd> | 跳到上一個／下一個標籤 |

詳見[播放與時間軸](/play/transport)。

## 時間軸標籤與片段把手

用滑鼠或 <kbd>Tab</kbd> 選中標籤或把手之後有效。

| 對象 | 按鍵 | 做什麼 |
| --- | --- | --- |
| 標籤 | <kbd>Enter</kbd> | 跳到這個標籤 |
| 標籤 | <kbd>F2</kbd> | 改名 |
| 標籤 | <kbd>Delete</kbd> | 刪除 |
| 片段把手 | <kbd>←</kbd> <kbd>→</kbd> | 移動 0.1 秒 |
| 片段把手 | <kbd>Shift</kbd>+<kbd>←</kbd> <kbd>→</kbd> | 移動 1 秒 |
| 片段把手 | <kbd>Home</kbd> <kbd>End</kbd> | 移到最前／最後 |

滑鼠操作：在時間軸上方的空白處雙擊加標籤；點標籤跳轉、拖曳移動、雙擊改名、右鍵開選單。

## 譜面紀錄的多選

在左側的譜面紀錄清單有效。

| 操作 | 做什麼 |
| --- | --- |
| <kbd>Ctrl</kbd>+點選 | 加入或移出選取 |
| <kbd>Shift</kbd>+點選 | 選取一段 |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | 全選目前清單（焦點在清單上時） |
| <kbd>Ctrl</kbd>+<kbd>Space</kbd> | 加入或移出焦點所在的那筆 |
| <kbd>Esc</kbd> | 結束選取 |
| <kbd>Shift</kbd>+<kbd>F10</kbd> | 打開這筆紀錄的選單（和右鍵相同） |

詳見[譜面紀錄](/charts/records)。

## 新增譜面與搜尋視窗

| 視窗 | 按鍵 | 做什麼 |
| --- | --- | --- |
| 新增譜面 | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | 生成並新增 |
| 編輯譜面 | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | 儲存 |
| 新增／編輯譜面 | <kbd>Esc</kbd> | 關閉視窗 |
| 搜尋譜面 | <kbd>Enter</kbd> | 搜尋 |
| 搜尋譜面 | <kbd>Esc</kbd> | 關閉視窗 |

## 標註分頁

在右側切到「標註」分頁時有效，這時的按鍵優先於播放用的按鍵。

| 按鍵 | 做什麼 |
| --- | --- |
| <kbd>A</kbd> | 這一步標左手 |
| <kbd>D</kbd> | 這一步標右手 |
| <kbd>Shift</kbd>+<kbd>A</kbd> ／ <kbd>D</kbd> | 整顆用同一隻手（有起點的 Slide 起點與滑行一次標完） |
| <kbd>S</kbd> | 切換這一步的信心（確定／不確定／皆可） |
| <kbd>Enter</kbd> | 確認這一步的預填 |
| <kbd>Delete</kbd> | 清除這顆的標註 |
| <kbd>N</kbd> | 跳到下一步還沒確認的 |
| <kbd>B</kbd> ／ <kbd>Shift</kbd>+<kbd>B</kbd> | 在這一步的各種打法之間輪流切換 |
| <kbd>G</kbd> | 分組：第一次按標這組的第一顆，再按一次標最後一顆 |
| <kbd>Esc</kbd> | 取消正在標的分組或分支 |

「逐顆標註」清單也能多選：<kbd>Ctrl</kbd>／<kbd>Shift</kbd>+點選、<kbd>Ctrl</kbd>+<kbd>A</kbd> 全選；選取時按 <kbd>A</kbd>／<kbd>D</kbd> 一次標全部選取的步驟，<kbd>Esc</kbd> 結束。

詳見[標註的基本操作](/annotate/basics)、[打法分支](/annotate/branches)與[分組](/annotate/groups)。

## 影片同步視窗

在影片同步視窗裡有效。標註用的按鍵會送到主視窗。

| 按鍵 | 做什麼 |
| --- | --- |
| <kbd>Space</kbd> | 播放／暫停影片 |
| <kbd>←</kbd> <kbd>→</kbd> | 上一格／下一格 |
| <kbd>Shift</kbd>+<kbd>←</kbd> <kbd>→</kbd> | 後退／前進 1 秒 |
| <kbd>R</kbd> | 重播這顆音符 |
| <kbd>↑</kbd> <kbd>↓</kbd> | 上一顆／下一顆音符 |
| <kbd>A</kbd> <kbd>D</kbd> | 標左手／右手（送到主視窗） |
| <kbd>S</kbd> | 切換信心（送到主視窗） |
| <kbd>Enter</kbd> | 確認預填（送到主視窗） |
| <kbd>N</kbd> | 下一顆還沒確認的（送到主視窗） |
| <kbd>Delete</kbd> | 清除這顆（送到主視窗） |

詳見[影片同步](/annotate/video)。

## 欄寬分隔線

拖曳欄與欄之間的分隔線調整寬度；雙擊（或選中後按 <kbd>Enter</kbd>）還原預設寬度。
