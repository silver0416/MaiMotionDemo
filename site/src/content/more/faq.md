使用者最常問的問題。每題先給簡短的答案，細節請點連結。

## 「找不到可行方案」是不是代表這張譜不能玩

不是。這只代表**目前的模型和這組參數**找不到雙手動作，不表示人類打不出來。可以試著調整搜尋寬度、切換交接或縮短片段後重新生成。見[方案](/play/solutions)。

## 方案裡有「模型略過的地方」是什麼意思

模型在那幾顆走不下去（兩手都被佔用、來不及移動等），先不指派手，其餘音符照常求解。略過不代表人類無法遊玩，只是目前的模型做不到。見[模型略過的地方](/model/skipped)。

## 分數（成本）越低就是越好打嗎

分數越低，只表示**在目前設定下模型越偏好**這種打法。它不是成功率、不是人類這樣打的機率，也不是玩家能力評估。見[方案](/play/solutions)與[評分怎麼算](/model/scoring)。

## 不同譜面的分數可以互相比較嗎

不行。分數是同一份譜面裡比較候選用的相對值；換了譜面、參數或評分方式，基準都不同。

## 結果是官方判定或唯一正確的打法嗎

都不是。結果是模型依規則推算的打法建議，參數是這個 Demo 的假設，不代表官方判定，也不是所有玩家的打法。手的動作也只是近似，沒有模擬手臂關節或真實手形。見[模型的限制](/model/limits)。

## 為什麼沒有音樂

這個程式只有譜面與動作展示，沒有音源播放，也沒有遊戲打分。搜尋匯入時也只下載譜面文字，不下載音樂、影片或封面。

## 盤面上的 Touch 位置和機台不太一樣

盤面上的曲線、Touch 落點與手掌半徑都是可辨識的近似，不是實機的軌道座標或感應區大小。見[simai 語法](/charts/simai)的「形狀和實機長得不一樣嗎」。

## 改了參數，盤面卻沒變

參數改完要重新生成。右下角會顯示「結果已過期」，按通知上的「重新生成」即可。播放倍率與「顯示」的設定只改畫面，不需要重新生成。

## 分析跑很久，可以取消嗎

沒有取消按鈕，「分析中」的通知上也沒有；但直接點別的譜面會立刻中斷目前的分析、切過去，開始新的分析或比對也會取代舊的。若最後回報「搜尋達到上限」，代表用完了約 20 秒的計算預算，可以縮短片段或在「參數」調小搜尋寬度。見[新增譜面](/charts/new)。

## 出現語法錯誤怎麼辦

依診斷標出的行、列位置修正。程式不會默默略過看不懂的音符，也不會把不支援的語法偷偷改成 Tap。支援的寫法見 [simai 語法](/charts/simai)。

## Majdata 或譜面網站搜尋、匯入失敗

先確認網路連線再重試。譜面可能已被移除，服務也可能暫時限流或改了公開存取規則。下載成功但語法不相容時，搜尋視窗會保留診斷，失敗的內容不會加入紀錄。見[搜尋匯入](/charts/search)。

## 同一首歌會不會被重複匯入

搜尋匯入與拖檔案進來時不會：已經匯入過的會標「已在本機」，或直接開啟原文相同的既有紀錄。在「新增」視窗手動貼上同樣的文字，則會再新增一筆。見[搜尋匯入](/charts/search)。

## 介面上的說明文字都不見了

介面預設是精簡模式。到「設定 → 外觀 → 說明文字」勾選「詳細模式」就會顯示。見[介面導覽](/start/interface)。

## 程式會連到哪些網站，會上傳我的譜面或影片嗎

不會上傳。左右手分析、影片的自動預填分析都在本機完成。程式只在這幾個時候連線：

- **每次開啟**：連到 GitHub 檢查有沒有新版（見[更新](/more/update)）。
- **搜尋譜面**：連線 simai Wiki、adxdls 或 Majdata，只下載譜面文字。
- **影片同步**：從 GitHub 下載 yt-dlp（與 Deno），並連線 YouTube 搜尋、下載影片，影片只存在本機。
- **影片的「自動預填」**：第一次使用時下載姿態偵測模型，存在本機，之後不再下載（見[從影片自動預填](/annotate/video-prefill)）。

## 更新之後紀錄還在嗎

在。紀錄、設定與下載的影片都存在本機，更新後全部保留。見[更新](/more/update)。

## macOS 打不開

macOS 版沒有簽章，第一次請在 Finder 對程式按右鍵選「打開」。見[下載與啟動](/start/install)。

## 刪錯紀錄了

刪除後，右下角提示上可以按「復原」。復原後要重新分析一次。見[譜面紀錄](/charts/records)。

## 在瀏覽器裡「生成」按鈕不能用

從原始碼單獨開的瀏覽器預覽沒有分析核心，不能解析或生成。請開啟桌面程式。見[從原始碼建置](/more/build)。

## 開發版一片空白或無法連線

開發版需要 Vite 的 1420 port。用 `npm.cmd run tauri dev` 同時啟動，或改用正式版執行檔。見[從原始碼建置](/more/build)。

## PowerShell 執行 npm 報路徑錯誤

改用 `npm.cmd`，避開本機 `npm.ps1` 啟動器的問題。見[從原始碼建置](/more/build)。

## 遇到問題想回報

在「設定 → 錯誤紀錄」按「複製並清除」，或在出錯的地方按「複製除錯資訊」，把內容和「設定 → 版本與更新」複製的版本資訊一起貼給開發者。見[設定](/more/settings)；各種情況要按哪個按鈕，見[遇到錯誤怎麼回報](/more/errors)。
