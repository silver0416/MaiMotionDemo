遇到錯誤時，不用自己截圖或整理：程式已經把需要的資訊打包好，按一個按鈕複製，整段貼給開發者就好。這頁依情況說明要按哪個按鈕、複製到的內容有什麼。

| 情況 | 在哪裡 | 按什麼 |
| --- | --- | --- |
| 比對時照標註走不下去 | 「標註」→「分享」 | 「複製標註」，再附上版本資訊 |
| 找不到方案、分析未完成 | 「方案」分頁，或新增譜面的視窗 | 「複製除錯資訊」 |
| 模型略過了幾顆 | 「方案」分頁的「評分」 | 「複製評分明細」 |
| 匯入譜面失敗 | 「設定 → 錯誤紀錄」 | 「複製並清除」 |
| 其他問題 | 「設定 → 版本與更新」 | 「版本資訊」旁的「複製」 |

## 比對時出現「照標註走不下去」

在「比對」分頁按「開始比對」後，可能會看到「模型照標註走不下去」，或「有 N 處照標註走不下去，已先略過」。先確認是不是自己標錯，再決定要不要回報：

1. 點提示下方的時間，或「照標註略過的地方」清單裡的那一列，跳到卡住的音符。
2. 檢查那裡的標註。常見原因是寫錯，導致同一隻手被分配到兩個同時出現的位置。標錯就直接改掉，再比對一次。
3. 確定沒有標錯、實際上就是這樣打時，保留標註，在「逐顆標註」編輯區的「備註」寫下說明，例如你實際怎麼打。
4. 切到「分享」分頁，按「複製標註」。
5. 打開「設定 → 版本與更新」，在「版本資訊」按「複製」。
6. 把這兩段整段貼給開發者。

「比對」分頁本身沒有複製按鈕；「複製標註」會把譜面、你的標註與備註一起打包，開發者拿到就能用同一份譜面與標註再比對一次。版本資訊裡有目前用的模型，所以要一起附上。比對時會發生什麼，見[和模型比對](/annotate/compare)。

## 找不到方案，或分析沒完成

「方案」分頁出現「沒有可用方案」或「分析未完成」時，下方有「複製除錯資訊」按鈕。新增或編輯譜面時，視窗裡出現「分析未完成」或語法錯誤的診斷，也有同一顆按鈕。

按下去會複製完整譜面、錯誤位置、參數與診斷。這些情況代表什麼、可以先怎麼調，見[略過與沒有方案](/model/skipped)。

## 模型略過了幾顆

「方案」分頁的「模型略過的地方」本身沒有複製按鈕。想回報時，用同一分頁「評分」下方的「複製評分明細」，它會複製完整譜面、參數與各候選方案的分數。

模型略過幾顆不表示人類打不出來，見[略過與沒有方案](/model/skipped)。

## 匯入譜面失敗

搜尋匯入、新增譜面或拖檔案進來失敗時，程式會自動記在「設定 → 錯誤紀錄」。左側欄的「設定」按鈕旁出現紅色數字，就是有還沒回報的紀錄。

1. 打開「設定 → 錯誤紀錄」。
2. 按「複製並清除」，把全部紀錄一次複製下來。
3. 整段貼給開發者。

複製成功後紀錄會自動清除；同一份建置再發生相同的錯誤，不會重複記錄。剪貼簿寫入失敗時紀錄不會清除，可以再按一次。

搜尋視窗裡的錯誤（下載失敗以外）也有「複製除錯資訊」，內容和錯誤紀錄裡的同一種。

## 其他問題

沒有上面這些按鈕的問題，到「設定 → 版本與更新」，在「版本資訊」按「複製」，連同你看到的情況一起貼給開發者。見[設定](/more/settings)。

## 複製出來的內容有什麼

### 「複製除錯資訊」與「複製評分明細」

- 產生時間、App 版本、發生的位置與分析狀態；
- 評分方式與完整參數；
- 問題點：錯誤訊息、原文的行與欄（附前後幾行並標出位置）、相關音符與譜面時間；
- 各候選方案的分數（有方案時）；
- 完整譜面原文。

不包含你的標註與備註。

### 「複製標註」

標註檔（和「匯出檔案」存下來的內容相同）：

- 完整譜面原文；
- 每顆音符標的手、信心、是不是預填、備註；
- 整體備註、區段備註、你的名字；
- 打法分支、分組；
- YouTube 影片網址與對齊（本機影片不會帶上）。

不包含比對結果與版本資訊，所以「照標註走不下去」時要另外附上版本資訊。

### 錯誤紀錄的「複製並清除」

每一筆匯入失敗的除錯資訊（內容同「複製除錯資訊」），加上匯入管道、失敗在哪一步、發生次數與時間。

### 版本資訊的「複製」

App 版本、應用程式種類、Build 號、判定規則修訂、目前的模型、「快速階梯一隻手刷完」開或關，以及評分方式。

## 貼的時候注意什麼

- **整段貼上，不要刪減。** 標註是 JSON 格式，少了一段就讀不回去；除錯資訊裡的譜面原文也要完整，才對得到錯誤的位置。
- **可以補一句說明**，例如你實際怎麼打、在哪個時間點覺得不對。
- **複製成功時**，按鈕會變成「已複製」，或出現「已複製標註」「已複製版本資訊」「已複製 N 筆錯誤紀錄」的通知。出現「無法寫入剪貼簿」時再按一次；標註也可以改按「匯出檔案」，把檔案交出去。
