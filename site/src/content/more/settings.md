按左側欄最下方的「設定」打開設定視窗，左邊是分類。這頁依分類說明每個設定的用途。

| 分類 | 用途 |
| --- | --- |
| 版本與更新 | 看版本資訊、檢查與下載更新 |
| 外觀 | 深淺模式、深色配色、說明文字的詳細模式 |
| 影片同步 | 管理 yt-dlp、Deno 與下載的影片（只有桌面版） |
| 匯出 | 標記檔的預設存檔資料夾（只有桌面版） |
| 資料管理 | 清除暫存資料，或清除全部資料 |
| 錯誤紀錄 | 匯入失敗的紀錄，複製後回報 |

左側欄的「設定」按鈕旁出現紅色數字時，代表有還沒回報的錯誤紀錄。

## 換成淺色或深色

「外觀 → 深淺模式」有三個選項：

- **跟隨系統**（預設）：照作業系統的深淺設定。
- **深色**
- **淺色**：固定使用「淺色工作室」配色，淺底適合白天與投影。

不論哪種模式，盤面永遠是黑底。主視窗和影片同步視窗會一起切換。

## 四組配色

深色模式有三組配色可選，在「外觀 → 深色配色」切換：

| 配色 | 特色 |
| --- | --- |
| 預設 | 冷灰底，左手粉、右手藍，系統字型 |
| 機台霓虹 | 偏藍紫的黑底，洋紅與青色更飽和，數字用 Chakra Petch 字型 |
| 暖墨 | 暖灰底，左右手改用珊瑚色與青綠色，標題用楷體 |

淺色模式固定使用第四組「淺色工作室」。目前是淺色模式時，這裡選的配色要切回深色才會生效。

## 打開說明文字

介面預設是精簡模式，只留標題、數字、狀態與錯誤警告。想看操作說明、欄位提示、圖例與通知內文，在「外觀 → 說明文字」勾選「詳細模式」。主視窗和影片同步視窗一起切換。詳見[介面導覽](/start/interface)。

## 版本資訊與複製

「版本與更新」最上方的「版本資訊」列出 App 版本、Build 號、應用程式種類、建置時間、判定規則修訂、目前的模型與評分方式。

- 按「複製」把這些資訊複製下來，回報問題時一起貼上。
- 按「查看更新內容」看各版的更新說明（需要連網）。

## 檢查更新

「版本與更新」下方的「軟體更新」可以按「檢查更新」，有新版時直接下載並重新啟動。每次開啟程式也會自動檢查一次。詳見[更新](/more/update)。

## 影片同步的工具與影片

「影片同步」分類管理對照手元影片要用的工具與檔案：

- **yt-dlp**：搜尋與下載 YouTube 影片用。YouTube 改版後舊版常會失效，下載失敗時先按「更新」。如果是系統自己裝的 yt-dlp，不由本程式更新。
- **JS 執行環境**：yt-dlp 需要它才能通過 YouTube 的檢查。已經裝了 Node.js 或 Deno 就不用另外下載；都沒有時按「下載 Deno」。
- **已下載的影片**：顯示部數與佔用空間，可以刪除個別影片，或按「全部清除」（要再按一次「確定清除」）。

刪除影片後，標註裡的影片連結與對齊都會保留，需要時再下載一次即可。影片同步怎麼用，見[影片同步](/annotate/video)。

## 標記檔要存到哪裡

「匯出」分類可以指定「預設匯出資料夾」，並勾選「不再詢問位置，直接存到預設資料夾」。直接存檔時同名檔案會自動加上編號，不會覆寫。詳見[匯出與匯入標記檔](/charts/bundles)。

## 清除暫存資料

「資料管理 → 清除暫存資料」會刪除：

- 已保存的分析結果（分析快取）；
- 標註比對的暫存；
- simai Wiki、adxdls 的索引與譜面快取。

譜面紀錄、標註、參數與顯示設定都會保留。之後開啟譜面時會重新分析，搜尋譜面網站時會重新下載索引。按「清除暫存」後要再按一次「確定清除」才會執行。

## 回到第一次啟動的狀態

「資料管理 → 清除所有使用者資料」會刪除全部譜面紀錄、參數與顯示設定、錯誤紀錄、分析與比對暫存、Wiki 快取，以及欄寬等介面偏好，回到第一次啟動的狀態。

**這個動作無法復原。** 按「清除全部」後要再按一次「確定全部清除」才會執行，程式會重新載入。要保留標註，先用[標記檔](/charts/bundles)匯出。

## 匯入失敗了想回報

譜面匯入失敗（下載失敗、分析核心呼叫失敗、語法錯誤或未支援的語法）會自動記在「錯誤紀錄」，相同的錯誤只記一筆並累計次數。

按「複製並清除」，把紀錄複製下來貼給開發者；複製後紀錄會自動清除，避免下次重複回報。其他錯誤怎麼回報，見[遇到錯誤怎麼回報](/more/errors)。
