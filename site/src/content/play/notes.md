想知道某一顆音符分給哪隻手、什麼時候開始滑、有沒有換手，就到「音符」分頁查它的明細。

## 選取一顆音符

有三種方式：

- **在盤面上點那顆音符**。右側會自動切到「音符」分頁（正在「標註」分頁時則留在標註）。
- **在「音符」分頁的清單裡點**。清單每列是編號、位置、種類、時間與目前分到的手；Hold 會寫持續幾秒，有煙火或一掌覆蓋也會註明。
- **按「目前時間音符」**：選取最接近目前播放時間的那顆，不會改變播放時間。暫停在某個瞬間、想知道這裡是哪顆時最方便。

按「取消選取」清除選取。被選取的音符在盤面上會以琥珀色加粗外框標出。

## 明細裡有什麼

| 欄位 | 內容 |
| --- | --- |
| 種類 | Tap、Hold、Slide、Touch、Touch Hold |
| 落點 | 鍵位或 Touch 落點 |
| 感應區 | 只有 Touch：在哪一圈，例如「外圈・鍵位方向」 |
| 形狀 | Slide 的形狀與起終點，例如「直線 1→5」 |
| 修飾 | Break、EX 等 |
| 判定時間、結束時間 | Hold 另外寫持續幾秒 |
| 移動開始、移動結束 | Slide 星星出發與抵達的時間 |
| 盤面座標 | 這顆音符在盤面上的位置 |
| 原文位置 | 在譜面原文的第幾行、第幾欄 |

下方的按鈕可以「跳到判定時間」，Slide 另有「跳到移動開始」。

## 這顆分給哪隻手

「目前候選的分配」表格把這顆音符拆成幾個部分，列出各由哪隻手、在哪段時間完成：

| 部分 | 意思 |
| --- | --- |
| 接觸 | Tap、Hold、Touch 的按壓 |
| Slide 起點 | 拍下星星 |
| Slide 軌道 | 沿軌道滑行 |
| Group 連帶判定 | 手沒有真的碰到，靠同組 Touch 連帶判定 |

表格下方會補充特殊情況：

- **中途換手**：寫出從哪隻手交給哪隻手、重疊的時段；兩條 Slide 碰頭互換時，會說明互換不需要移動，沒有重疊時間。
- **兩手同時各滑一段**：例如 WiFi 由兩手分工時，會寫「L 與 R 同時各滑一段」。
- **被模型略過**：寫出模型在幾秒走不下去，這顆的哪一部分（起點、滑行或接觸）沒有指派手。見[模型略過的地方](/model/skipped)。

切換候選方案後，這裡跟著換成那個候選的分配。

## 每個候選怎麼處理這顆

有兩個以上的候選時，最下方「候選之間的差異」並排列出每個候選對這顆音符用哪隻手，以及各候選的三群分數（效率／姿態／負荷）。點候選名稱就切過去。

## 一掌覆蓋的資訊

選到被手掌一起蓋住的 Touch 時，會多一塊「一掌覆蓋」：

- 哪隻手；
- 覆蓋落點與覆蓋音符；
- 覆蓋區間與時長；
- 掌心位置與半徑。

這一掌會佔用到其中最晚放開的時刻，期間那隻手不接別處。按「跳到覆蓋開始」「跳到覆蓋結束」可以直接跳過去。手掌半徑的意思見[手掌覆蓋](/model/palm)。

## 連帶判定是什麼

同一時刻、判定區相鄰的 Touch 會組成一組（Touch Group），實際碰到超過半數時，剩下的會連帶判定。模型只在手真的接不到時才這樣安排，方案會註明，音符明細標示「Group 連帶判定」，盤面標籤寫成「L連帶」或「R連帶」。詳見[判定與空手的技巧](/model/judgement)。

## 中央的 C 落點

simai 的 `C`、`C1`、`C2` 都當成同一個中央落點，共用中央這一個位置。
