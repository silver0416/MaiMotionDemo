「顯示」分頁決定盤面上要畫哪些東西。這裡的設定**只改畫面**，不會重新分析，也不會改變方案或任何時間資料。

## 盤面太亂，想關掉一些東西

「顯示內容」裡每一項都可以單獨開關：

| 項目 | 預設 | 說明 |
| --- | --- | --- |
| 顯示譜面音符 | 開 | 關掉只看手的動作 |
| 顯示左手 L（粉紅） | 開 | 只看右手時可以關掉 |
| 顯示右手 R（藍） | 開 | 只看左手時可以關掉 |
| 顯示最近軌跡 | 開 | 手後面拖著的一小段粗線 |
| 顯示整段軌跡 | 關 | 整首的移動畫成細線；長譜面會佈滿盤面 |
| 在音符旁標出 L／R | 開 | 音符旁的分配標籤，見[看懂盤面](/start/disc) |
| 顯示換手標記 | 開 | 換手時的琥珀色菱形 |
| 顯示手掌覆蓋區 | 開 | 一掌覆蓋時的虛線大圓 |
| 顯示 1–8 鍵位編號 | 開 | 外圈的鍵位數字 |
| 顯示煙火效果 | 開 | 煙火 `f` 的擴散效果 |

## 軌跡要拖多長

「最近軌跡長度」設定手後面那段粗線顯示往前幾秒的移動，預設 1.2 秒，可以調 0.2–4 秒。

想看一整段的路線，打開「顯示整段軌跡」；搭配[循環片段](/play/transport)只看一小段會更清楚。

## 音符一次全部顯示

「音符呈現」有兩種：

- **依時間出現**（預設）：音符在判定前才出現。可以開關「音符飛入動畫」：Tap／Hold／Slide 由中心飛向鍵位，Touch 在原地由外往落點收攏。「飛入時間」設定音符提前多久出現，預設 0.85 秒，可以調 0.2–2 秒。
- **全部同時顯示**：整首的音符都畫在盤面上。

飛入只是視覺效果，不改變判定時間。

## 手掌覆蓋區只是畫面

「顯示手掌覆蓋區」只在模型判定一掌覆蓋時才會出現，畫在音符與手的軌跡下層。覺得擋到就關掉；關掉只隱藏畫面，不改變方案。

## 想對照 Touch 的位置

「Touch 落點標記」會在盤面上畫出 33 個可以用 simai 指名的 Touch 落點（灰色的小多邊形）：

| 選項 | 效果 |
| --- | --- |
| 關閉 | 不畫（預設） |
| 有 Touch 時顯示 | 譜面有 Touch 時才畫 |
| 一律顯示 | 每份譜面都畫 |

- 打開時可以再選「標記上顯示區域編號」，在標記上寫出 A1、B3 這類編號；密集的譜面可以關掉編號，只留外形。
- 這份譜面真的用到的落點會畫得比較明顯。
- A／D 用四邊形，B／E 用三角形，C 用中央八邊形。

這些輪廓是辨識用的示意，不代表實機感應區的大小。

## 煙火效果

煙火 `f` 只在起始判定後短暫擴散一次，Touch Hold 結束時不會再放。效果完全跟著播放時鐘，拖曳時間軸到同一秒會看到相同的畫面。不想看可以單獨關掉「顯示煙火效果」。

## 放大盤面

「盤面校準與縮放」裡的「檢視縮放」只放大畫面，範圍 0.6×–2×，預設 1×。

## 盤面中心與半徑校準

一般不需要動。如果盤面看起來偏掉，可以調：

- 「圓心 X」「圓心 Y」：圓心的位置。
- 「盤面半徑」：盤面的大小。
- 勾選「顯示校準圓環與十字線」對照調整。

盤面是向量繪製，會和音符一起移動。校準**只改畫面上的位置與大小**，不改分析用的幾何資料與搜尋結果。調亂了，按「還原校準與縮放」回到預設。

## 圖例在哪裡

在詳細模式下，「顯示」分頁中間有「Touch 區圖例」與「手掌覆蓋圖例」，說明各種外形的意思；精簡模式下會收起來。完整的圖形說明見[看懂盤面](/start/disc)。

## 設定會記住嗎

會。「顯示」的設定存在本機，下次開啟照舊，換譜面也不會重設。
