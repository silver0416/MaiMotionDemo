盤面下方的播放列可以慢放、停在任何一個瞬間、反覆播放一小段，也能在時間軸上插標籤記住重要的位置。

## 播放、暫停與回到開頭

| 按鈕 | 做什麼 | 按鍵 |
| --- | --- | --- |
| 「播放」／「暫停」 | 開始或暫停播放 | <kbd>Space</kbd> |
| 「重置」 | 回到開頭 | <kbd>Home</kbd> |
| `‹ 0.1s`、`0.1s ›` | 後退／前進 0.1 秒 | <kbd>←</kbd>／<kbd>→</kbd> |
| | 後退／前進 1 秒 | <kbd>Shift</kbd>+<kbd>←</kbd>／<kbd>→</kbd> |

按鈕旁顯示目前時間與整首長度。

## 放慢速度

播放列右邊可以選 `0.25×`、`0.5×`、`1×`、`2×`。倍率**只改播放時鐘**，不會改分析結果，也不需要重新生成。

## 停在某個瞬間

直接拖曳時間軸，盤面就停在那一刻，顯示兩隻手的位置。拖到同一個時間點，看到的畫面永遠相同（包括煙火效果）。

時間軸上的小刻度是每顆音符，顏色跟著分到的手；上緣的細條是手掌覆蓋的區間，琥珀色的區段是 Slide 換手。

## 時間是負的是什麼意思

時間軸開頭可能是負的時間，時間軸上會有一條 0 秒的標線。負時間是第一顆音符之前，手先移到起始位置的**預備動作**。

## 反覆播放一小段

想反覆看某一段難的地方：

1. 停在這段的開頭，按「設為起點」（<kbd>I</kbd>）。
2. 停在這段的結尾，按「設為終點」（<kbd>O</kbd>）。
3. 勾選「循環片段」（<kbd>L</kbd>），播放就會在這段之間反覆。

用 <kbd>I</kbd>／<kbd>O</kbd> 設定時，循環會自動打開。

- 時間軸下方有兩個**片段把手**，可以直接拖曳調整起點與終點。選中把手後，方向鍵每次移 0.1 秒、<kbd>Shift</kbd>+方向鍵移 1 秒、<kbd>Home</kbd>／<kbd>End</kbd> 移到最前或最後。
- 循環打開時，範圍外的時間軸會變暗、音符刻度變灰。
- 按「整段」，片段回到整首並關閉循環。

## 在時間軸上加標籤

標籤用來記住重要的位置，例如「副歌」「難點」。要先開啟一份譜面並生成結果，才能加標籤。

- **加標籤**：按 <kbd>M</kbd> 或播放列上的「標籤」，在目前時間加一個；也可以在時間軸上方的空白處**雙擊**。
- **跳過去**：點一下標籤；按 <kbd>[</kbd>／<kbd>]</kbd> 跳到上一個／下一個標籤。
- **移動**：拖曳標籤。
- **改名**：雙擊標籤，輸入名稱後按 <kbd>Enter</kbd>。
- **更多動作**：在標籤上按右鍵，有「跳到這裡」「重新命名」「設為片段起點」「設為片段終點」「刪除標籤」。

用鍵盤選中標籤時，<kbd>Enter</kbd> 跳過去、<kbd>F2</kbd> 改名、<kbd>Delete</kbd> 刪除。

時間軸標籤會跟著[標記檔](/charts/bundles)一起匯出。

## 播放用的按鍵

| 按鍵 | 做什麼 |
| --- | --- |
| <kbd>Space</kbd> | 播放／暫停 |
| <kbd>←</kbd> <kbd>→</kbd> | 後退／前進 0.1 秒 |
| <kbd>Shift</kbd>+<kbd>←</kbd> <kbd>→</kbd> | 後退／前進 1 秒 |
| <kbd>Home</kbd> | 回到開頭 |
| <kbd>L</kbd> | 開關循環片段 |
| <kbd>I</kbd> ／ <kbd>O</kbd> | 目前時間設為片段起點／終點 |
| <kbd>M</kbd> | 在目前時間加標籤 |
| <kbd>[</kbd> ／ <kbd>]</kbd> | 跳到上一個／下一個標籤 |

游標在文字輸入欄裡時，這些按鍵不會被攔截，可以正常打字。所有按鍵整理在[快捷鍵](/more/shortcuts)。

## 時間軸旁的左右手狀態

在詳細模式下，循環片段那一列的右邊會顯示兩隻手目前在做什麼（例如「移動中」「按住」）和正在處理的音符。精簡模式下這一塊會收起來，見[介面導覽](/start/interface)。
