這頁回答「評分方式那幾張卡差在哪、該選哪一張」。

## 評分方式在哪裡選

「參數」分頁最上方的「評分方式」：

| 位置 | 卡片 |
| --- | --- |
| 最上方 | 一張「TemotoAI-2」：浅葱色（預設） |
| 「顯示更多模型」裡 | 「V4.3」「V4.1」「V4」「V3.2」「V3.1」「V3」；另外兩張「TemotoAI-2」：鉛丹色、山吹色；以及全部七張 TemotoAI-1：紺瑠璃、偏藍的菖蒲色（しょうぶいろ）、瑠璃紺、偏粉的菖蒲色（あやめいろ）、瑠璃色、茜色、常磐色 |

同一系列的卡片名稱相同，靠卡片右下角的顏色區分。「顯示更多模型」裡的卡留著方便對照；收起來時如果選的是裡面的卡，按鈕後面會寫「（已選 …）」。

換了評分方式要重新生成才會套用。分析結果依評分方式分開保存，換回之前分析過的評分方式會直接載入，不必重跑。

## V4.3、V4.1、V4、V3.2、V3.1、V3 是什麼

這六個是同一套搜尋、同一種[成本](/model/overview)，差在考慮的事情多寡和權重。每一版都包含前一版的全部內容，再往上加：

**V3**：人類動作模型的原始版本，三群分數（動作效率、姿態與分工、短期負荷）的基本版。

**V3.1**：用較新的一批真人標註重新擬合權重，規則不變。

**V3.2**：把「星星由一手拍下卻由另一手滑」的成本調低。

**V4**：多考慮四件事。

- 很快連續（0.06 秒內）的相鄰音符，傾向同一隻手帶過。
- 雙押時兩手不交叉，從另一側來幫忙的手打下面那顆。
- 同時好幾個 Touch 散得太開（一隻手掌要張到半徑 0.37 以上才蓋得住）時，傾向兩手分著拍。
- 等間隔又快（0.13 秒內）的三顆一組，頭尾同一鍵、中間換鍵（例如 6、5、6）時，傾向兩手交互。

**V4.1**：再多考慮兩件事。

- 兩手都空著一段時間後，單顆音符傾向由靠那一側的手打。
- 和長押同時按下的 2 到 4 顆，兩手分著按時不交叉；散得太開時也不一隻手硬包。

**V4.3**：再多考慮三件事，都和節奏有關。預設的浅葱色 TemotoAI-2 就是以它為基座。

- 好幾串快速階梯接在一起時，每一串交給一隻手、下一串換另一隻手；第一串由大部分音符所在那一側的手開始。
- 同一個鍵連按兩顆時用同一隻手，接著換到別的鍵的那顆換另一隻手。
- 很快的同一鍵連打，兩手輪流。

這六個版本都會使用「參數」裡的四個打法偏好，見[參數](/model/params)。

## TemotoAI 是什麼

TemotoAI 不是另一套從零開始的打法，而是在基座上修正：

1. 先用基座（V4.3、V4.1 或舊版）跑一次完整的分析。
2. 再依模型的判斷，修正其中部分音符的左右手，重新計算手的動作。
3. 結果仍交給核心確認做得到。做不到的修正沿用基座的手。

「方案」分頁最上方會寫出這次修改了幾個手順；如果修正在這份譜面整份走不下去，也會註明改用基座的結果。

因為要多跑一輪，**分析時間是基座的數倍**。

### TemotoAI-2

新一代的模型。浅葱色、鉛丹色與山吹色是同一代的三個版本：浅葱色是預設，以 V4.3 為基座；鉛丹色與山吹色以 V4.1 為基座，收在「顯示更多模型」裡；三個都以自動分組（模型自己找出的常見音符組，見[連打、階梯與滑移](/model/taps)）為單位判斷整組的手型。

### TemotoAI-1

TemotoAI-1 的卡都在「顯示更多模型」裡，各接不同的基座：

| 卡片 | 基座 |
| --- | --- |
| 紺瑠璃、菖蒲色（しょうぶいろ） | V4.1 |
| 瑠璃紺、菖蒲色（あやめいろ） | V4 |
| 瑠璃色 | V3.2 的權重 |
| 茜色 | V3.1 |
| 常磐色 | V3 |

紺瑠璃和瑠璃紺是同一個模型分別接 V4.1、V4；菖蒲色（しょうぶいろ）和菖蒲色（あやめいろ）也是同一個模型分別接 V4.1、V4。瑠璃紺則是瑠璃色的模型改接 V4。

幾張卡採用修正的門檻不同：

- 常磐色只採用模型把握 60% 以上的修正，其餘卡 50% 以上就採用。
- 紺瑠璃、兩種菖蒲色、瑠璃紺與瑠璃色另外以自動分組為單位判斷整組的手型，比基座合理時整組改用；含 Touch 的組不整組改。

這裡的「把握」是模型內部的門檻，不是人類選這種打法的機率。

## 選 TemotoAI 時哪些設定不使用

選了 TemotoAI-2 或 TemotoAI-1，打法由模型決定：

- 「參數」的四個打法偏好滑桿（左右分工傾向、快速移動容忍、同點連打容忍、Slide 換手意願）**不使用**，那一區的標題會變成「規則」。
- 「允許 Slide 中途換手」「Slide 依判定區抄近」「Hold 可以提早放手」「快速階梯一隻手刷完」這些規則開關，以及手掌設定，**照常有效**。

## 該選哪一個

- 沒有特別的需求：用預設的浅葱色 TemotoAI-2。
- 想看一份可以用滑桿調整偏好、分析也比較快的建議：打開「顯示更多模型」選「V4.3」。
- 想看另一種修正過的手順來對照：換「顯示更多模型」裡的其他 TemotoAI-2 或 TemotoAI-1。
- 想比較新舊版本差在哪：打開「顯示更多模型」。
- 想知道哪個模型最貼近某位玩家的打法：先[標註](/annotate/basics)，再到「比對」用模型選單逐一[比對](/annotate/compare)。

不論哪一張，結果都是模型依規則推算的建議，不代表官方判定或唯一正確的打法。
