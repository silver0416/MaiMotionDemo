simai 是用文字寫 maimai 譜面的格式。這頁先用白話講最基本的節奏寫法，再列出這個程式支援的全部語法與限制，寫譜或看錯誤訊息時可以回來查。

## 一段 simai 怎麼讀

```simai
(120){4}1,8,2,7,E
```

| 寫法 | 意思 |
| --- | --- |
| `(120)` | BPM 120，也就是一拍 0.5 秒 |
| `{4}` | 分割：之後每個逗號推進一個 4 分音符（一拍） |
| `1` `8` `2` `7` | 鍵位 1–8 上的 Tap |
| `,` | 逗號推進一格時間；兩個逗號之間沒寫音符就是空一格 |
| `E` | 譜面結束，最後要寫成 `,E` |

所以上面這段是：0 秒按 1、0.5 秒按 8、1 秒按 2、1.5 秒按 7。

<Demo id="simai-timing" />

換算方式：一拍是 60 ÷ BPM 秒，`{n}` 的一格是 n 分音符，也就是 4 ÷ n 拍。`(120){8}` 一格 0.25 秒，`(120){2}` 一格 1 秒。`(BPM)` 和 `{分割}` 可以在譜面任何位置改。

不想用拍子算，也可以用 `{#0.25}` 直接指定每格 0.25 秒。

## 同時按好幾顆

用 `/` 連起來，或直接把鍵位連寫：

```simai
(120){4}1/5,18,E
```

`1/5` 與 `18` 都是兩顆同時。

## Hold：按住一段時間

`1h[4:1]` 是在 1 號鍵按住一個 4 分音符長。`[n:m]` 的意思是 **m 個 n 分音符**。

```simai
(120){4}8h[4:4]/1,2,3,4,E
```

8 號鍵按住 4 個 4 分音符（2 秒），同時 1 號鍵有一顆 Tap，接著是 2、3、4。按住 Hold 的那隻手整段都被佔住，後面的音符要由另一隻手接。以預設參數為例，左手按住 8，右手依序點 1、2、3、4。

<Demo id="hold-other-hand" />

Hold 長度的其他寫法：`1h[#1.5]` 直接寫 1.5 秒，`1h[120#4:1]` 用 BPM 120 換算。只寫 `1h`、不寫長度，視為長度 0 的 Hold。

## Slide：星星出發前會等一拍

```simai
(120){4}1-5[4:3],8,7,6,E
```

`1-5[4:3]` 是從 1 直線滑到 5、滑行長度 3 個 4 分音符。一般 Slide 的規則是：

1. 起點的星星在判定時間被拍下；
2. **先等一拍**，星星才出發；
3. 再用指定的長度滑到終點。

這段的星星在 0 秒拍下、0.5 秒出發、2 秒滑到 5；滑行期間還有 8、7、6 三顆 Tap。等待的這一拍不會把起點那隻手整段鎖住，可以先去做別的事。

<Demo id="slide-basic" />

以預設參數為例，右手在 0 秒拍下星星，0.5 到 0.85 秒滑了前面一小段就停下；左手先點 8、7、6，1.75 秒再從右手停下的那一點接著滑到 5。這不算換手，音符旁標成 `R起L滑`。

## 長 Slide 與自訂等待

`[等待秒##移動規格]` 可以自己指定等多久、滑多久：

```simai
(120){4}8>4[1##3],,,,,,,8,E
```

`8>4[1##3]` 在 8 號鍵拍下星星，等 1 秒，再花 3 秒沿圓弧滑到 4，滑完是第 4 秒。後面七個逗號把時間推到 3.5 秒，8 號鍵再出現一顆 Tap，這時這條 Slide 還沒滑完。播放時留意這顆 Tap 由哪隻手去接：以預設參數為例，是拍下星星的左手。它只滑了一小段就離開去準備這顆 8，Slide 剩下的部分由右手在 3 秒從同一點接著滑完，音符旁標成 `L/R`。

<Demo id="slide-long" />

Slide 長度的寫法：

| 寫法 | 意思 |
| --- | --- |
| `[4:1]` | 滑 1 個 4 分音符，等待一拍 |
| `[#1.5]` | 滑 1.5 秒，等待一拍 |
| `[160#8:1]` | 用 BPM 160 換算：等待一拍、滑 1 個 8 分音符 |
| `[1##3]` | 等 1 秒、滑 3 秒 |
| `[##4:1]` | 等待留空就是一拍 |

## Slide 有哪些形狀

<Demo id="shapes" />

以預設參數為例，`3^6`、`7q3`、`1s5`、`2V84` 由拍下星星的手畫完；`1-5` 與 `5v2` 由另一隻手接著滑（標籤 `R起L滑`、`L起R滑`）；`8w4` 是 WiFi，兩隻手同時各滑一段（`L+R滑`）。

| 符號 | 畫面上的名稱 | 限制 |
| --- | --- | --- |
| `-` | 直線 | 終點要和起點相隔 2–6 格 |
| `^` | 圓弧 | 只接受短於半圈的圓弧 |
| `<` `>` | 逆向圓弧、順向圓弧 | |
| `v` | 折返中心 | |
| `V` | 大 V | 寫成 `2V84`，轉折鍵必須是起點左右各兩格 |
| `p` `q` | 左繞圈、右繞圈 | |
| `pp` `qq` | 左大繞圈、右大繞圈 | |
| `s` `z` | S 形、Z 形 | 只能連到正對面的鍵位 |
| `w` | Wifi | 只能連到正對面的鍵位 |

起終點的幾何不合法時，會報錯並標出位置。

## 形狀和實機長得不一樣嗎

盤面上的曲線與位置是這個 Demo 的可辨識近似，不是實機的軌道座標，而且**會影響成本高低**：

- `p` `q` `pp` `qq` 畫成沿指定方向捲進內圈、繞行再捲出。
- `s` `z` 畫成通過中心的平滑 S／Z。
- `w` 以中央那條當手的移動路徑，另外畫出兩條側線。
- Touch 的 A／D 在外圈、B／E 在內圈，D 與 E 相對旋轉半格。

## 支援語法總表

| 類型 | 寫法 |
| --- | --- |
| BPM 與分割 | `(120)`、`{4}`；可在任何位置變更 |
| 固定秒數步長 | `{#0.25}` |
| 推進與結束 | 逗號推進一格；最後用 `,E` |
| 註解 | `\|\|` 之後到行尾 |
| Majdata 顯示速度 | `<HS*1.5>`；會讀取並提示，不套用落下顯示速度 |
| Tap | `1`–`8` |
| 同時音 | `/`，或直接連寫 `18`；疑似 EACH 用反引號 `` ` `` |
| 音符修飾 | Break `b`、EX `x`、星形 `$`、旋轉星 `$$` |
| Hold | `1h[4:1]`、`1h[#1.5]`、`1h[120#4:1]`；省略長度的 `1h` 視為長度 0 |
| Touch | `A1`–`A8`、`B1`–`B8`、`C`（`C1` `C2`）、`D1`–`D8`、`E1`–`E8`，煙火 `f` |
| Touch Hold | `Ch[4:1]`、`C1h[#1]f`；省略長度的 `Ch` 視為長度 0 |
| Slide 形狀 | `-` `^` `<` `>` `v` `V` `p` `q` `pp` `qq` `s` `z` `w` |
| Slide 長度 | `[4:1]`、`[#1.5]`、`[160#8:1]`、`[等待秒##移動規格]` |
| Slide 組合 | 連續 `1-3-5[4:1]`、接續 `1-3[4:1]-5[4:1]`、同頭 `1-3[4:1]*-7[4:1]` |
| 無起點 Slide | `1?-5[4:1]`、`1!-5[4:1]` |
| Slide 修飾 | 長度後面加 `b` 或 `x` |
| Majdata Break Slide | 長度前也可加 `b`，如 `2>6qq4b[4:1]` |

語法的正式定義見 [simai 說明](https://w.atwiki.jp/simai/pages/1002.html)。

## 目前不支援的寫法

- WiFi 與其他形狀共用一個時間括號的複合寫法，會回報位置與原因；各段各自寫時間的接續寫法仍可使用。
- 不支援的語法一律回報來源位置與原因，不會被默默略過或改成 Tap。

## 反引號的時間位移

反引號 `` ` `` 用來寫「疑似 EACH」，也就是幾乎同時、但有一點先後的音符：

- 貼整份 `maidata.txt`，或譜面裡用了 Majdata 的 `<HS*倍率>` 時，反引號分開的音符間隔用 Majdata 的 128 分音符。
- 一般 simai 本文保留原有的位移。

## Break、EX 會改變打法嗎

不會。Break 與 EX 只影響實機判定，盤面上會換筆觸顏色（見[看懂盤面](/start/disc)），但不改變模型的動作。
