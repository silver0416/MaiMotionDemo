左側欄的「譜面紀錄」存著你新增或匯入的每一份譜面。譜面一多，可以用資料夾分類、加標籤、篩選與排序，或一次選好幾筆批量處理。

## 每一筆紀錄顯示什麼

每筆紀錄以**名稱**為主標、**新增時間**為副標；放在資料夾裡的會註明資料夾，有標籤的會列出標籤。點一下就開啟那份譜面。

在紀錄上按右鍵，或按旁邊的「⋯」，會出現這些動作：

| 動作 | 做什麼 |
| --- | --- |
| 查看／編輯 | 打開「編輯譜面」改名或改原文，見[新增譜面](/charts/new) |
| 整首備註… | 寫這份譜面的整體備註 |
| 匯出標記檔 | 存成一個檔案分享，見[匯出與匯入標記檔](/charts/bundles) |
| 標籤… | 加上或拿掉標籤 |
| 移到資料夾… | 換資料夾 |
| 選取 | 進入多選模式 |
| 全選目前清單 | 選取目前看得到的所有紀錄 |
| 刪除 | 刪除這筆紀錄（可以復原） |

## 用資料夾分類

清單上方第一排是資料夾：「全部」「未分類」與你建立的各資料夾，點一下切換。

- 最右邊的按鈕新增資料夾。
- 資料夾只有一層，一筆紀錄只放在一個資料夾。
- 在資料夾上按右鍵，可以「重新命名」「匯出資料夾內的標記檔」或「刪除資料夾」。
- 刪除資料夾時，裡面的紀錄改回「未分類」，不會被刪掉；提示上可以按「復原」。

## 用標籤分類

第二排是所有標籤。一筆紀錄可以有好幾個標籤。

- **點選標籤**：只顯示有這些標籤之一的紀錄。
- **右鍵**：可以隱藏、重新命名、換顏色或刪除標籤。
- 重新命名成已經有的名稱，兩個標籤會**合併**。
- 加標籤時，在「標籤」面板輸入新名稱後按 <kbd>Enter</kbd> 就會建立並加上。

## 暫時藏起某些紀錄

在標籤上按右鍵選「隱藏這個標籤的紀錄」，有這個標籤的紀錄會整批不出現在清單裡（紀錄本身沒有刪除）。就算同時有別的標籤正在篩選，也一樣藏起來。

- 隱藏的標籤畫成**虛線框**，前面是閉眼圖示，數字是它藏起來的筆數；點一下就再顯示。
- 篩選列下方會寫「隱藏了 N 筆」，按「全部顯示」一次取消所有隱藏。
- 資料夾與「全部」的數字，只算沒被隱藏的紀錄。

## 找某一份譜面：篩選與排序

- **篩選**：輸入框可以依名稱、曲師、譜師、上傳者與標籤篩選。輸入框右側的 × 一次清除文字與標籤篩選，但**不會取消隱藏**。
- **排序**：旁邊的選單可選「最新新增」「最早新增」「最近開啟」「名稱」「難度高到低」「標註最多」。

目前的資料夾、標籤篩選、隱藏的標籤與排序都會記住，下次開啟照舊。

## 一次選好幾筆

進入選取的方式：

- 在紀錄上按右鍵選「選取」。之後點一下就加入或移出選取，不會開啟譜面。
- 按住 <kbd>Ctrl</kbd> 點選，加入或移出一筆。
- 按住 <kbd>Shift</kbd> 點選，選取一段。
- 在清單裡按 <kbd>Ctrl</kbd>+<kbd>A</kbd>，全選目前清單。
- 按 <kbd>Esc</kbd> 結束選取。

選取時，「譜面紀錄」標題列會收起，空出的位置換成選取工具列，顯示「已選 N 筆」與四個按鈕：匯出、標籤、移到資料夾、刪除。清單本身不會移動。在選取的紀錄上按右鍵，也有同樣的批量動作。

## 用拖的移動紀錄

把一筆紀錄（或整批選取的紀錄）拖到上方的資料夾或標籤上，就會移進那個資料夾或加上那個標籤。拖到「未分類」就是移出資料夾。

## 刪錯了怎麼辦

刪除時會先問一次「刪除這筆紀錄？」（多選時是「刪除 N 筆紀錄？」），確認後才刪。刪除之後，右下角的提示上可以按「復原」把紀錄救回來。

復原時，這份譜面的分析快取與比對暫存不會保留，重新開啟時會再分析一次。

想一次清掉所有紀錄，在「設定 → 資料管理」，見[設定](/more/settings)。
