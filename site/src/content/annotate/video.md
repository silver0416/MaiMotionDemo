這頁回答「怎麼一邊看手元影片一邊標註」。流程是：開影片視窗 → 找到影片 → 對齊第一顆一次 → 之後在主視窗選任何音符，影片都會自動跳到那裡慢速播一遍。

## 怎麼打開影片視窗

在「標註」分頁上方按「影片同步」，會開一個獨立的「影片同步比對」視窗，可以拖到另一個螢幕。

影片視窗跟著主視窗目前開啟的譜面；主視窗還沒開譜面時，請先在左側開啟一筆紀錄。

影片視窗右側有三個分頁：「對齊與跟隨」「找影片」「自動預填」。前兩個是這頁的內容；「自動預填」讓程式看影片推測左右手，見[從影片自動預填](/annotate/video-prefill)。

## 怎麼找到影片

在影片視窗的「找影片」：

- **搜尋 YouTube**：預設用「曲名＋難度＋maimai 手元」搜尋，也可以改關鍵字，或直接貼上影片網址。改過關鍵字後可以按「改回預設」。
- **開啟本機影片**：用自己錄的影片。

搜尋與下載僅桌面版可用。

### 第一次使用要下載的工具

| 工具 | 什麼時候需要 | 大小 |
| --- | --- | --- |
| yt-dlp | 第一次搜尋或下載 YouTube 影片前 | 約 18 MB |
| Deno（JS 執行環境） | YouTube 需要 JS 執行環境。已安裝 Node.js 或 Deno 就直接使用；都沒有時按「下載 Deno」 | 約 45 MB，免安裝，不需要系統管理員權限 |

沒下載 Deno 就去抓影片而失敗時，錯誤訊息也會附上「下載 Deno」的按鈕。

### 影片會存在哪裡

影片只下載 720p 以下的畫面，**沒有聲音**，存在本機，不會上傳。

## 影片左右相反怎麼辦

有些手元影片是鏡像拍的，畫面裡的左手其實是玩家的右手。這時在「對齊與跟隨」分頁的「影片」區打開「左右翻轉」（選好影片後才會出現），影片就會左右鏡像顯示。

- 這個設定跟著影片連結一起存，也會照「譜面＋影片」和對齊一起記住；分享 YouTube 影片的標註時也會帶過去。
- [從影片自動預填](/annotate/video-prefill)會照這個設定對調左右手，所以鏡像的影片要先打開它再分析。

## 怎麼對齊影片和譜面

只要對齊一次：

1. 播放或逐格（<kbd>←</kbd>／<kbd>→</kbd>）把影片停在**第一顆音符被打到的那一格**。
2. 按「設為第一顆」。

也可以停在目前選取的音符被打到的那一格，按「設為選取的音符」。

對齊後可以微調與檢查：

- **微調**：「−1 格」「+1 格」「−10ms」「+10ms」。判定那一格看起來還沒打到就按「+1 格」，已經打完就按「−1 格」。
- **檢查**：按「最後一顆」看最後一顆是否也對得上；對得上，整首就沒有跑掉。也可以看「第一顆」或「選取的音符」。

## 選音符時影片會做什麼

在主視窗選到音符（包括標完自動跳到下一顆）時，影片預設會：

1. 從判定前 0.4 秒開始，以 0.5 倍速播放；
2. 播到判定後 0.3 秒；
3. 停回判定那一格。

在「選音符時」可以改：

| 模式 | 效果 |
| --- | --- |
| 播放片段（預設） | 照上面的方式慢速播一段。判定前、判定後的秒數與速度都可以選，也可以取消「播完停回判定那一格」 |
| 只跳過去 | 直接停在判定那一格 |
| 不跟隨 | 選音符時影片不動 |

按 <kbd>R</kbd> 重播這顆。

## 兩個視窗怎麼互相跟隨

已對齊時：

- **播放、暫停與播放速度兩邊共用**，在哪個視窗按都一樣。
- 在影片視窗逐格或拖曳，主視窗的盤面跟著動。快速拖曳或按住方向鍵時，畫面會盡快跟上最後的位置。
- 在主視窗拖曳時間軸，影片跟著動。
- 一起播放時，影片以微調速度對齊主視窗，不會中途跳格。

例外：

- 影片還沒對齊，或停在譜面開始之前（片頭）時，影片視窗的播放只播影片，盤面不跟著動。
- 2× 時螢幕一秒顯示不了影片的全部畫面。要逐格看快速的手部動作，請用 0.5× 或逐格。

## 在影片視窗直接標註

不必切回主視窗，標註按鍵會送到主視窗：

| 按鍵 | 作用 |
| --- | --- |
| <kbd>A</kbd>／<kbd>D</kbd> | 左手／右手 |
| <kbd>S</kbd> | 信心 |
| <kbd>Enter</kbd> | 確認預填 |
| <kbd>N</kbd> | 下一顆未確認 |
| <kbd>Delete</kbd> | 清除這顆 |
| <kbd>↑</kbd>／<kbd>↓</kbd> | 上一顆／下一顆音符 |
| <kbd>Space</kbd> | 播放影片 |
| <kbd>←</kbd>／<kbd>→</kbd> | 逐格 |
| <kbd>Shift</kbd>+<kbd>←</kbd>／<kbd>→</kbd> | 移動 1 秒 |
| <kbd>R</kbd> | 重播這顆 |

各按鍵的意思見[逐顆標註](/annotate/basics)。

## 對齊會記在哪裡

- 影片與對齊偏移存在**這份譜面的標註**裡。
- 另外會照「譜面＋影片」記住對齊：換過影片、解除連結，或刪掉紀錄重新加入後，選回同一部影片會自動帶回上次的對齊。

## 分享標註時影片怎麼處理

分享標註檔時會附上 YouTube 網址與對齊偏移，對方匯入後一鍵下載就能直接對齊。**本機影片不會分享出去**。分享的方法見[備註與分享](/annotate/notes-share)。

## 已下載的影片怎麼管理

「找影片」裡已下載的影片，預設只列**這份譜面**的影片：

- 在這份譜面開著時下載或選用的影片，以及標註已連結的影片，會自動歸到這份譜面。
- 打開「顯示所有影片」可以看全部。
- 在影片上按右鍵（或 ⋯）可以使用、歸到或移出這份譜面，或刪除影片。使用中的影片要先換別部才能刪。

## 在設定裡管理影片

「設定」的「影片同步」可以：

- 更新 yt-dlp（YouTube 改版後舊版常會失效，下載失敗時先更新）；
- 刪除個別影片；
- 一次清除所有下載的影片。

刪除後，標註裡的影片連結與對齊仍會保留，需要時再下載即可。
