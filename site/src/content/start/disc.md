盤面是整個程式的主角。這頁一次講清楚盤面上每種圖形代表什麼，看動畫時就知道該盯哪裡。

<Demo id="disc-legend" />

盤面永遠是黑底，音符都是中間挖空的粗外框，不會遮住下面的軌跡與手。外圈的 1–8 是鍵位編號（可以在「顯示」關掉）。

## 音符長什麼樣子

| 音符 | 盤面上的樣子 |
| --- | --- |
| Tap | 粗圓環，中間挖空、正中心一個小點；先在內圈原地放大，再飛向鍵位 |
| Hold | 空心長條，兩端收成六邊形的尖角。頭在判定位置，尾巴往盤面中心延伸，長度代表要按多久；開始判定後尾端往頭收，剩下的長度就是剩餘時間。尾端中心的小點是放開的位置 |
| Slide | 一顆中間挖空的星星飛到鍵位，加上沿軌道排成一整排的箭頭。拍下去之後，星星先停在起點，再沿軌道滑到終點；走過的箭頭會消失，只留下還沒走的那段。每個箭頭都墊著一圈黑邊，兩條軌道疊在一起時也看得出一個一個的箭頭 |
| WiFi Slide | 一整面扇形的箭頭，從起點攤開到三個終點；三顆星星同時前進、同時抵達 |
| Touch | 上下左右四片圓角三角形，尖端朝著落點，中間挖空；落點正中心一個帶白邊的小圓點。三角形從外往落點收攏，**四個尖端碰在一起的瞬間就是判定時間**，這時四片剛好拼成一個正方形，落點周圍亮起一個圓角方框 |
| Touch Hold | 四片三角形改擺在四個斜角，收到位時拼成一個菱形。按下去之前沒有外框；按住之後，外面一圈粗的圓角菱形從正上方順時針一段一段亮起來，亮滿一圈就是放開的時間 |

Tap、Hold、Slide 會先在內圈原地放大，再飛向鍵位；Slide 的起點星星會邊飛邊轉，到鍵位時剛好轉回一個角朝外。Touch 則是在原地出現，而且比同一時間的 Tap 晚一點：先在落點周圍淡入，接著慢慢往內靠，快到判定時才一下子合起來，不從中心飛出去。飛入只是視覺效果，不改變判定時間；可以在「顯示」關掉，或改成全部同時顯示（見[顯示](/play/view)）。

打開「Touch 落點標記」與編號時，Touch 正中心的小圓點會改寫成落點名稱（例如 B3）。

同一個時間要按的兩顆外圈音符，中間會連一條細圓弧，跟著音符一起飛向鍵位。

音符是白色的，粉紅與藍只留給左右手。想看遊戲的配色，可以在「顯示」打開「照遊戲上色」；想在判定的那一刻看到遊戲那種六角形的光暈，可以打開「打擊效果」（見[顯示](/play/view)）。這頁的演示都用白色音符，也不畫打擊效果。

## Touch 的五種落點

<Demo id="touch-kinds" />

這段依序出現 A1、B3、C、D5、E7，最後是 C 的 Touch Hold；A1、C、D5 與最後的 Touch Hold 有煙火。以預設參數為例，右手點 A1、B3、D5 並按住最後的 Touch Hold，左手點 C 和 E7。

Touch 的落點分成五區。外形只是辨識用的示意，不代表實機感應區的大小。

| 區 | 位置 | 落點標記的外形 |
| --- | --- | --- |
| A1–A8 | 外圈，鍵位方向 | 四邊形 |
| B1–B8 | 內圈，鍵位方向 | 三角形 |
| C | 中央 | 八邊形 |
| D1–D8 | 外圈，鍵位之間 | 四邊形 |
| E1–E8 | 內圈，鍵位之間 | 三角形 |

simai 的 `C`、`C1`、`C2` 都當成同一個中央落點。「落點標記」是盤面上灰色的小多邊形，預設關閉，要對照時到「顯示」打開。

## 煙火、Break 與 EX 怎麼畫

- **煙火（`f`）**：判定前會先在落點外圍畫一圈虛線預告；到判定時間在落點擴散一次。拖時間軸到同一秒，看到的效果完全相同。
- **Break**：換成橘色，形狀不變。
- **EX**：音符周圍多一圈柔和的光暈，貼著外緣往外淡出。Touch 與 Touch Hold 不畫，遊戲裡這兩種音符沒有 EX 的樣子。

Break 與 EX 只影響實機判定，不改變模型的動作。

## 左手與右手

- **L**：左手，粉紅色圓形。
- **R**：右手，藍色圓形。

手碰到盤面時，圓形外面會多一圈接觸環。手的標記下方會寫目前在做什麼：

| 狀態 | 意思 |
| --- | --- |
| 移動中 | 抬手移往下一個目標 |
| 滑移中 | 不抬手、貼著面板滑到相鄰鍵位 |
| 敲擊 | 正在點 Tap 或 Touch |
| 按住 | 正在按 Hold 或 Touch Hold |
| 滑行 | 正在畫 Slide |
| 交接中 | Slide 正在交給另一隻手 |
| 手掌覆蓋 | 一隻手掌同時蓋住好幾個 Touch |
| 待命 | 沒有工作 |

在「設定 → 外觀」把深色配色換成「暖墨」時，左右手會改用珊瑚色與青綠色。

## 手的軌跡

- **最近軌跡**：手後面拖著一段粗線，顯示最近一小段時間（預設 1.2 秒）的移動。預設開啟。
- **整段軌跡**：把整首的移動畫成細線。預設關閉，因為長譜面打開後盤面會佈滿細線。

兩隻手的軌跡都是實線，用顏色區分。

## 音符旁邊的標籤

每顆音符旁會標出它分給哪隻手，字的顏色跟著手走。一顆音符只會有一個標籤，由上往下，符合哪一種就寫哪一種：

| 標籤 | 意思 |
| --- | --- |
| `L→R` | 這顆中途換手，從左手交給右手（琥珀色） |
| `L+R滑` | 兩隻手同時各滑一段，例如 WiFi 由兩手分工（`L`、`R` 各用自己的手色） |
| `L連帶` | Touch Group 連帶判定：手沒有真的碰到，靠同組其他 Touch 一起判定 |
| `L起R滑` | Slide 起點由左手拍，軌道由右手滑 |
| `L`、`R` | 其餘情況，列出用到的手：通常就是左手或右手；少數情況同一顆兩隻手都有參與，會寫成 `L/R` |

左右對調的寫法（`R→L`、`R起L滑`、`R連帶`…）意思相同。標籤預設顯示，可以在「顯示」分頁的「在音符旁標出 L／R」關掉。

連帶判定是什麼，見[判定與空手的技巧](/model/judgement)。

## 換手的菱形

Slide 中途換手時，交接的位置會出現一個**琥珀色菱形**，上面寫「換手 L→R」；兩條 Slide 碰頭互換時寫「兩手互換」。菱形只在換手前後短暫出現。

時間軸上也會用琥珀色標出換手的區間。

## 手掌的虛線圓

一隻手掌同時蓋住好幾個 Touch 時，盤面會畫出：

- 一個用該手顏色畫的**大圓虛線**，中間是掌心十字；
- 被蓋住的每個 Touch 外圍再加一圈同色虛線；
- 旁邊寫「L 手掌・一次覆蓋 3 個 Touch」和蓋到的落點。

時間軸上緣的細條，是該手的手掌覆蓋區間。這些位置、半徑與時間都來自分析結果；覺得擋到畫面可以在「顯示」關掉，不會改變方案。手掌怎麼算，見[手掌覆蓋](/model/palm)。

## 選取的音符

點一下盤面上的音符就會選取它，外框改用琥珀色加粗；右側會自動切到「音符」分頁顯示明細（正在「標註」分頁時則留在標註）。見[音符](/play/notes)。
