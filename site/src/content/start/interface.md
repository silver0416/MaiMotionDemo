這頁是整個程式的地圖：每一區在哪裡、做什麼，以及怎麼把說明文字打開或收起來。

<Demo id="layout-tour" />

點演示上的各區可以看說明；打開上方的「窄視窗」開關，可以看視窗不到 900px 寬時的上下排列（見[視窗很窄時](#視窗很窄時)）。

## 三欄各放什麼

| 欄 | 內容 |
| --- | --- |
| 左：譜面紀錄 | 上方有「收合側欄」「新增」「搜尋譜面」；中間是資料夾、標籤、篩選與紀錄清單；最下方是「設定」，它右邊的問號是「使用指南」，會用瀏覽器開啟這份手冊 |
| 中：盤面與播放列 | 盤面動畫；下方是播放、倍率、時間軸、循環片段與時間軸標籤 |
| 右：資訊分頁 | 「方案」「音符」「參數」「顯示」「標註」五個分頁 |

點左側的一筆紀錄就會開啟那份譜面。分析或載入時，盤面、時間軸與右側會先顯示載入骨架；分析中直接點別的譜面，會中斷目前的分析、立刻切過去。

## 右側五個分頁

| 分頁 | 做什麼 | 詳見 |
| --- | --- | --- |
| 方案 | 比較候選方案、看兩手分工、換手與模型略過的地方 | [方案](/play/solutions) |
| 音符 | 看選取音符的時間、分給哪隻手、滑行區段 | [音符](/play/notes) |
| 參數 | 選評分方式、調整打法偏好，改完要重新生成 | [模型可以調的參數](/model/params) |
| 顯示 | 軌跡、標籤、手掌覆蓋區、Touch 落點標記、縮放與盤面校準 | [顯示](/play/view) |
| 標註 | 記錄真人實際的左右手，和模型比對，或開影片對照 | [標註的基本操作](/annotate/basics) |

在盤面點一顆音符時，右側會自動切到「音符」分頁；正在「標註」分頁時則留在標註。

## 想改原文要去哪裡

右側沒有編輯分頁。要改一份譜面的名稱或原文，在左側那筆紀錄上按右鍵（或按旁邊的「⋯」），選「查看／編輯」，會打開「編輯譜面」視窗。詳見[新增譜面](/charts/new)。

## 調整欄寬與收合左欄

- 拖曳欄與欄之間的分隔線可以調整寬度；**雙擊分隔線**還原預設寬度。
- 按左欄上方的「收合側欄」，左欄縮成一條直立膠囊，只留展開、新增、搜尋與設定四個按鈕。
- 欄寬與收合狀態會記住，下次開啟照舊。

視窗變窄時欄寬會跟著收，盤面永遠留得下來。

## 說明文字怎麼都不見了

介面預設是**精簡模式**：欄位提示、快捷鍵、圖例、時間軸旁的左右手狀態、候選方案的統計列，以及一般通知的內文都收起來，只留標題、數字、狀態與錯誤警告。錯誤與警告的通知仍會顯示原因。

想看說明：

1. 按左下角「設定」。
2. 選「外觀」，在「說明文字」勾選「詳細模式」。

主視窗和影片同步視窗會一起切換。滑鼠停在按鈕上出現的提示不受影響，兩種模式都看得到。

## 視窗很窄時

視窗寬度不到 900px 時，三欄改成**上下排列**，整頁可以捲動，分隔線隱藏；所有操作仍然可以用。左欄收合時會變成橫向的一列按鈕。

## 參數改了，畫面卻沒變

改了「參數」之後，盤面還是舊參數的結果。右下角會一直顯示「結果已過期」，按通知上的「重新生成」就會用新參數重新分析。播放倍率和「顯示」裡的設定只改畫面，不需要重新生成。

## 從舊版升級

從 v1.1.4 或更早的版本更新上來，第一次開啟時右下角會有一則「介面已切換至精簡模式」的通知，上面可以直接打開「詳細模式」。
